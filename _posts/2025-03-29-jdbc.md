## 들어가며

데이터를 저장하려면 어떻게 해야할까?

자바 환경에서 데이터베이스 연결을 위한 표준 API 

자바와 데이터베이스를 연결하기 위한 표준 인터페이스를 제공한다. 그리고 각 dB 벤더들이 이 jdbc를 구현한 드라이버를 구현체로 사용한다.

**JDBC(Java Database Connectivity)**는 자바 애플리케이션과 데이터베이스 간 연결 및 SQL 실행을 위한 **표준 API**입니다.  
이를 통해 자바에서 데이터베이스 접속, 쿼리 실행, 결과 처리 등을 일관되게 할 수 있습니다.

정리하면:
- 자바와 DB 사이의 표준 인터페이스
- 다양한 RDBMS를 동일한 API로 다룸
- DB 벤더별 드라이버로 구체 구현 제공


전체적인 흐름은? 
애플리케이션 -> JDBC API -> 드라이버 -> DB

드라이버 매니저가 라이브러리에 저장되어있는 db 드라이버를 검색함. 그리고 해당 드라이버를 통해 커넥션을 가져오도록 구현이 된다.
