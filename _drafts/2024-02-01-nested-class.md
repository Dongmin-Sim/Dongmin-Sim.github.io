## 들어가며

JVM은 자바를 WORA할 수 있게 도와주는 가상 머신이다. 가상 머신




static 
- **바깥 클래스의 인스턴스와 무관하게 사용됨**
- **의도**: 바깥 클래스와 논리적으로는 관련 있지만, 바깥 클래스의 인스턴스에 의존하지 않는 경우 사용
- **주 용도**: 유틸성 객체, 빌더 패턴, enum 내부 정의 등

inner
- **바깥 클래스의 인스턴스에 암묵적으로 연결됨 (`Outer.this` 접근 가능)**
- **의도**: 바깥 인스턴스의 필드나 메서드를 활용하고자 할 때 사용



아니요, **외부 클래스가 언로드(unload)되면 static 중첩 클래스도 함께 언로드됩니다.**
### 이유:

- `static 중첩 클래스`는 **외부 클래스의 네임스페이스(scope)** 안에 존재하기 때문에,
    
- JVM의 클래스 로더는 **외부 클래스와 함께 로드되고 함께 언로드**합니다.
    
- 외부 클래스가 메모리에서 내려가면 해당 정적 클래스도 접근할 수 없습니다.
    

즉, `static` 키워드로 인해 **외부 클래스 인스턴스 없이 사용 가능**하지만,  
**외부 클래스 정의 자체와는 생명주기를 공유**합니다.
